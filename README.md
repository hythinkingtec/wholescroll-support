# Whole Scroll Support

Feedback and bug reports for Whole Scroll.

Prefer the in-extension **Support** flow (or [Support](https://www.wholescroll.com/support.html)) when you can — it can include a screenshot and recent capture context. You can also open a GitHub issue here.

This repo is feedback only, not the product source.

1. Search existing issues first.
2. New issue → **Bug report**.
